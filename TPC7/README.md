## Resumo 
O objetivo deste TPC é desenvolver uma aplicação em Python que funciona como um teste de aferição, focada na consolidação de competências de programação através de três blocos de exercícios: listas por compreensão, funções e gestão de dados de uma rede social.

####  Tpc1. Listas em Compreensão:
    a) Criação de uma lista com os elementos que não são comuns a duas listas dadas.

    b) Formação de uma lista com palavras de um texto que possuam mais do que 3 letras.

    c) Geração de uma lista com o formato (índice, valor) a partir dos elementos de uma lista.

#### Tpc2. Funções
    a) Calcula o número de vezes que uma substring não vazia ocorre numa string, sem sobreposições.

    b) Recebe uma lista de inteiros positivos e calcula o menor produto possível multiplicando os 3 menores inteiros da lista.

    c) Função que soma repetidamente os dígitos de um número inteiro positivo até obter apenas um único dígito final.

    d) Procura a primeira ocorrência de uma string dentro de outra, devolvendo o respetivo índice ou -1 caso não exista.

#### Tpc3. Gestão de uma Rede Social
    a) quantosPost - Contagem do número de post registados

    b) postsAutor - Retorna a lista de posts criados por um determinado autor 

    c) autores - Retorna por ordem alfabética os autores presentes na rede social

    d) insPost - Acrescenta um novo post a partir dos parâmetros recebidos e devolve a nova rede social
    O campo `id` devrá ser calculado a partir dos já existentes, por exemplo, se a rede tiver posts com id `p1`, `p2` e `p3`, o novo `id` deverá ser `p4`.

    e) remPost - Elimina um post da rede com base no ID fornecido.

    f) postsPorAutor -  Agrupa e contabiliza os posts associados a cada autor.

    g) comentadoPor - Devolve a lista de posts que foram comentados por um determinado autor.
