## Resumo 

Neste trabalho foram realizadas duas atividades utilizando a plataforma Blockly.games.
Na primeira atividade foi desenvolvida a solução do nível 10 do jogo Labirinto. Após a conclusão do desafio, foi capturada uma imagem (screenshot) comprovando a resolução obtida.
Na segunda atividade foi reproduzido o desenho fornecido pelo docente recorrendo ao jogo Tartaruga da plataforma Blockly. Para tal, foram utilizados blocos de programação que permitiram desenhar a figura proposta.
